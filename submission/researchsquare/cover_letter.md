# Cover letter (Research Square)

Dear Research Square,

We are submitting the preprint **"Verifiable Incentives: Identity-Bound Contracts and Collusion-Proof Delegation for Agent Commerce"** as a Research Article.

The paper develops a principal-agent framework for verifiable delegation in agent commerce, with results on identity, collusion, and staking, an architecture (PAIR-Commerce), a 60-task benchmark (AgentCommerce-Bench), and a chain of real-model experiments. It reports both null results for instruction-following agents and positive results for economically motivated agents, including a repeated economic sandbox, and a semi-field study on real merchant catalogs. It also releases a real-money sandbox implementation with a Stripe test-mode validation; no live payment is claimed.

Suggested keywords: agent commerce; verifiable delegation; principal-agent; collusion; incentive compatibility; agent identity; agent wallets; benchmarking.

The manuscript is original and is not under review at a journal. Code and data are available at https://github.com/88z44v9mkf-bot/verifiable-incentives.
