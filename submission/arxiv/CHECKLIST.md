# arXiv submission checklist

1. **Wait for the monthly limit.** The account used earlier had 2/2 submissions in November; the limit resets on 1 December. Confirm the submission page shows an available slot.
2. **Upload** `paper/main.pdf` (25 pages). arXiv accepts PDF-only submissions, but TeX source is preferred; if moderators ask for source, provide the Markdown/HTML build pipeline in the repository (a TeX conversion is the next step if needed).
3. **Paste metadata** from `PASTE.txt` (title, authors, abstract, comments, categories, license).
4. **Categories**: primary cs.AI; cross-list cs.MA and cs.GT.
5. **License**: arXiv non-exclusive distribution 1.0 (consistent with the earlier paper).
6. **Preview** the PDF and the abstract page; check that the abstract is ASCII (no en/em dashes, no multiplication sign).
7. **Submit** and record the submit/ID and announcement date.
8. **After announcement**: add the arXiv ID to the README and to the Research Square record.
